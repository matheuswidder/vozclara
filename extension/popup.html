Bandeja
Modelo

O Setup do zip instala uma vez. Depois use Ligar o motor (atalho na área de trabalho). A extensão só verifica se a bandeja responde — não baixa o .exe.

Português (e inglês/espanhol) descarta chinês, japonês e outros alfabetos que o modelo misturar.

Ajuda
Extensão e motor
A extensão é o botão no WhatsApp. O motor é o ícone na bandeja do Windows, ao lado do relógio. Whisper no Chrome não usa motor. Nemotron usa.
Bandeja Ligado ou Desligado
Verde: pode transcrever. Cinza: clique em Ligar. “Não instalado”: rode o Setup do zip, uma vez.
Preciso do Setup de novo?
Não, se só recarregou a extensão — transcrever segue. Sim, se o painel pedir Atualize, ou se quiser o modelo sair da memória depois do clique (PC com pouca RAM).
Os dois pontos
Bandeja = o programa. Modelo = o arquivo no disco. Sobe na memória só no clique e sai no fim.
