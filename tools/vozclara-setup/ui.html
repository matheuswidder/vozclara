VozClara Motor

Um programa pequeno no seu Windows. Ele transcreve os áudios do WhatsApp sem enviar nada para a internet. Fica escondido ao lado do relógio, como o antivírus.

  1. Copiar o programa nesta pasta
  2. Preparar o Python
  3. Instalar o que o Nemotron precisa
  4. Criar atalho na área de trabalho
  5. Ligar o ícone ao lado do relógio

      

      

      

      
      

        O Windows pode mostrar um aviso azul na primeira vez — o arquivo
        ainda não tem certificado pago. Clique em Mais informações
        e Executar assim mesmo. O áudio não sai deste PC.
        Para desligar depois: clique com o botão direito no ícone da bandeja → Sair.
