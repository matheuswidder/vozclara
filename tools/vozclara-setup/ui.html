VozClara Motor

Instala o Nemotron neste computador e deixa o motor ao lado do relógio, em segundo plano. O Chrome só conversa com ele.

  1. Copiar os arquivos
  2. Encontrar o Python
  3. Instalar as bibliotecas
  4. Criar o atalho
  5. Ligar na bandeja do Windows

      

      

      
      

        Se o Windows mostrar um aviso azul, clique em Mais informações e
        Executar assim mesmo. Só nesta primeira vez.
